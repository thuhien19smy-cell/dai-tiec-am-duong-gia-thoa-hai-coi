# Đại Tiệc Âm Dương - Giao Thoa Hai Cõi

Trải nghiệm và thiết kế nghi thức Đại Tiệc Âm Dương – Đêm Kinh Dị Dân Gian Việt Nam theo phong cách giao thoa văn hóa điện ảnh giữa Halloween phương Tây và tín ngưỡng dân gian Việt Nam.

## Tính năng chính
- Khám phá hành trình và thông điệp sự kiện Đại Tiệc Âm Dương
- Trải nghiệm giao thoa văn hóa giữa Vị Khách & Gia Chủ
- Đặt vé trực tuyến với các hạng vé linh bài
- Bản đồ chỉ đường, timeline chương trình và thông tin liên hệ

## Công nghệ sử dụng
- React 19, TypeScript, Vite
- Tailwind CSS
- Lucide React & Motion
- Express backend
